# Audiolab — IndicF5 ZeroGPU

Free-first Gradio Space for authorized voice generation with AI4Bharat IndicF5.

The app accepts a reference recording, its exact transcript, and generation text. It supports the 11 languages supported by IndicF5.

Only use recordings you own or have explicit permission to use.

## ZeroGPU

Select **ZeroGPU** hardware for this Space. The GPU is allocated only while the generation function runs.
